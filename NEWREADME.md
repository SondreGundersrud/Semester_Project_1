# Semester Project 1 - Portfolio 1 CA

Purpose of this project is to simulate a website for a museum through HTML and CSS, and now JS.

## Description

The website will allow the user simulate the experience of visiting a website for the local museum, with clickable buttons that lets the user browse mulitple activities and read more about special topics.
Visiting the museum's website will give the user all they need in order to figure out what activites are available, prices, location etc.

- Clickable navigation bar
- Clickable boxes that expand and shows more content inside.

## Built With

- HTML
- CSS
- JS
